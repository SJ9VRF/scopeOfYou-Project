# Submission strategy

## Current controlled evidence

The most defensible NeurIPS contribution type for the executed CPU behavioral study alone is **Concept & Feasibility**: the core contribution is a high-risk formulation with preliminary controlled evidence and an explicit falsification path.

## After the frozen LLM + public benchmark + human study gates

If two independent generative model families, public benchmarks, and human validation reproduce the selective-personalization result, the strongest target becomes **General** or **Use-Inspired**, depending on whether the final paper emphasizes the method or the persistent-assistant use case.

## Do not submit the current controlled package as if it were an LLM SOTA paper

The code deliberately separates executed results from planned external validation. Public benchmark adapters and the LoRA backend are infrastructure, not outcomes.

## Double-blind release rule

The NeurIPS submission source and supplementary ZIP must remove author identity, public homepage links, repository URLs tied to the author, acknowledgments, and identifying metadata. The public portfolio version is a separate artifact.
