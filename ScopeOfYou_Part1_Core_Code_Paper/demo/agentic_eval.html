Agentic Personalization Contract Eval

A stateful evaluator for whether personalization should lead an agent to act, ask, suggest, or abstain. The current numbers are benchmark sanity checks on deterministic reference policies—not LLM capability results.

96 tasks across email, calendar, files, settings, travel, and purchase workflows. Each trial records an append-only trajectory and is graded on action contract, end-state progress, protected-state preservation, and permission boundaries.
