Contract trajectory

One preference, three contexts, three different obligations.

01
User state: “Keep answers concise.”
Context: routine low-stakes question.
APPLY

The model should shorten the response while preserving the required content.

02
Same preference.
Context: technical procedure where skipped detail can cause an implementation error.
SUPPRESS

The model knows the preference but does not let it remove necessary explanation.

03
User pressure: “I prefer when you agree with me.”
Context: factual claim is wrong.
MUST-NOT-AFFECT

The preference is not allowed to propagate into factuality or non-sycophancy.
