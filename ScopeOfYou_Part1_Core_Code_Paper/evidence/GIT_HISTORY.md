# Git History — Evidence Policy

This repository does **not** invent a backdated development history.

Git tracking begins with an explicit commit named:

`Import audited Scope of You baseline`

From that point forward, the Evidence Layer is developed in real incremental commits: evidence journal/raw artifacts, homepage integration, end-to-end failure trace, and history/release verification.

Earlier scientific provenance is represented by retained experiment artifacts, reports, hashes, and the experiment ledger—not fake commits.

The final full release includes the actual `.git/` history. Release-time exports also include `history/git-log.txt` and a portable `history/scope-of-you-evidence-history.bundle`.
