# NeurIPS submission package

`neurips_submission.tex` is the anonymous submission source. It intentionally does **not** bundle a style file copied from an unofficial mirror. Before submission, place the official `neurips_2026.sty` from the NeurIPS submission package next to the source and append the mandatory checklist from the official template.

The current NeurIPS handbook requires the official yearly style, anonymous review material, a nine-page main-text limit (references/appendix/checklist excluded), and the mandatory paper checklist. The public `main.tex` keeps the project author visible; do not submit that public version for double-blind review.

Before submission, the LLM-scale and human-study gates described in `docs/LLM_PAPER_RUNBOOK.md` and `docs/HUMAN_EVAL_PROTOCOL.md` should be executed if the intended contribution type is General rather than Concept & Feasibility / controlled mechanistic evidence.
