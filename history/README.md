# Real Git History Boundary

This repository intentionally does not backfill or backdate commits for work that happened before Git tracking began in this release.

The history starts with:

`Import audited Scope of You baseline`

Everything after that baseline import is a real incremental commit made while adding and validating the Evidence Layer. Earlier research provenance is represented by retained experiment outputs, hashes, reports, and the experiment ledger—not invented commit history.

Release packages include:

- the repository `.git/` directory in the full research archive;
- `history/git-log.txt`, generated from the real repository at release time;
- `history/scope-of-you-evidence-history.bundle`, a portable Git bundle generated from the same history.

The local commit identity uses `Aura Yavary` and a non-routable project-local email solely because Git requires an email field. It does not claim a public contact address.
